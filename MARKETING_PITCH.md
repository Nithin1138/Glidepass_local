## ⚡ The Four Powers

### 1. **Flash Paste** ⚡ The Speed Racer
Instant clipboard injection. Hit your phone. Text appears on your desktop before you can blink.
- **Use case:** Code snippets, API keys, error logs, links
- **Speed:** 50ms end-to-end
- **Perfect for:** Developers moving code from Stack Overflow to IDE

### 2. **Human-Like Typing** ⌨️ The Ghost Writer
Simulates real human typing at your chosen speed. Types like a *real person*, not a bot—with natural rhythm and randomness.
- **Use case:** Banking portals, forms that block pasting, secure command-line interfaces
- **Settings:** 40–120 WPM, 20% variance
- **Perfect for:** Entering credentials in locked-down environments

### 3. **Code Inject** 💻 The Cleaner
Pastes code *intelligently*. Strips auto-indentation. Clears the "staircase effect." Just works.
- **Use case:** Moving Python/JavaScript/SQL code from phone to IDE
- **Perfect for:** Late-night debugging when you can't use your laptop keyboard

### 4. **Live Sync** 🔴 The Real-Time Typist
Type on your phone. Watch it appear, character-by-character, on your desktop in real time.
- **Use case:** Writing essays, long-form notes, live coding walkthroughs
- **Perfect for:** Demonstrating code to an audience while using your phone as the input
